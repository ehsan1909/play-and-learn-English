# پروژه اندرویدی Play and Learn English

این پوشه یک پروژه Android Studio است. فایل HTML اصلی در مسیر `app/src/main/assets/index.html` قرار دارد و بازی پنجم «تمرین تلفظ» به آن اضافه شده است.

## نکته‌های مهم
- بازی تلفظ از موتور **Vosk** و مدل کوچک انگلیسی استفاده می‌کند.
- تشخیص گفتار در زمان اجرای APK روی خود گوشی انجام می‌شود؛ برای خود بازی تلفظ اینترنت لازم نیست.
- در اولین ساخت پروژه، Android Studio باید کتابخانه‌ها و مدل را از اینترنت دریافت کند.
- مدل انگلیسی داخل APK بسته‌بندی می‌شود؛ بنابراین اندازه APK از یک برنامه HTML ساده بزرگ‌تر خواهد بود.
- گزینهٔ «شنیدن تلفظ» در بازی حذف شده است. پس از هر پاسخ (درست یا غلط)، صدای MP3 همان واژه از فایل‌های صوتی داخلی برنامه پخش می‌شود.
- بازی فقط بررسی می‌کند که واژه گفته‌شده توسط موتور تشخیص گفتار درست تشخیص داده شده یا نه؛ این امتیازدهی، آزمایش تخصصی آواشناسی یا نمره دقیق لهجه نیست.
- حداقل نسخه Android پروژه API 23 است؛ اندروید 8.1 گوشی LG Q6 از این حد بالاتر است (API 27).

## قدم اول: نصب Android Studio
1. روی لپ‌تاپ وارد صفحه رسمی شوید: https://developer.android.com/studio
2. Android Studio را دانلود و نصب کنید.
3. در اولین اجرا، گزینه‌های نصب پیشنهادی را قبول کنید و اجازه دهید Android SDK نصب شود.

## قدم دوم: باز کردن پروژه
1. فایل ZIP پروژه را از حالت فشرده خارج کنید.
2. Android Studio را باز کنید.
3. در صفحه شروع روی **Open** بزنید.
4. پوشه اصلی `PlayAndLearnAndroid` را انتخاب کنید؛ همان پوشه‌ای که فایل `settings.gradle` در آن است.
5. اگر Android Studio برای دانلود Gradle یا SDK اجازه خواست، تأیید کنید. برای این مرحله اینترنت لازم است.
6. صبر کنید تا پیام **Gradle Sync** تمام شود. اولین بار ممکن است چند دقیقه طول بکشد.

## قدم سوم: ساخت APK
1. از منوی بالای Android Studio وارد **Build** شوید.
2. گزینه **Build Bundle(s) / APK(s)** را انتخاب کنید.
3. روی **Build APK(s)** کلیک کنید.
4. بعد از پایان ساخت، روی **locate** بزنید تا فایل APK را پیدا کنید.
5. فایل `app-debug.apk` را به گوشی منتقل و نصب کنید.

## قدم چهارم: آزمایش
1. APK را روی گوشی نصب و اجرا کنید.
2. وارد یک درس شوید و بازی پنجم **تمرین تلفظ** را باز کنید.
3. بار اول اجازه استفاده از میکروفون را بدهید.
4. صبر کنید تا مدل آفلاین آماده شود؛ بارگذاری اولیه ممکن است کمی زمان ببرد.
5. روی «شروع ضبط» بزنید و واژه را با صدای بلند بگویید.

## اگر خطا دیدی
از صفحه خطا یا پیام Gradle Sync عکس بگیر و همین‌جا بفرست. چیزی را حدس نزن و تنظیمات دیگر را تغییر نده؛ بر اساس همان خطا مرحله بعد را می‌گویم.

## فایل HTML
برای تغییرات بعدی، نسخه داخل `app/src/main/assets/index.html` را جایگزین کن و سپس در Android Studio دوباره APK بساز.
